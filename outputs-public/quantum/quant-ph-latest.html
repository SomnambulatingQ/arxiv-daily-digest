可分离性不能证明零噪声外推：动态量子电路中的因子诊断主分类

2610.28705v1

Separability does not certify zero-noise extrapolation: Factorial diagnostics in dynamic quantum circuits

作者：Aryan Kumar

主分类：quant-ph 公告类型：new

quant-ph

中文摘要

分别放大门、延迟与中电路测量误差可以简化零噪声外推，但放大旋钮之间的弱交互作用并不能确立准确的零噪声极限。本文区分可观测量的可分离性、响应模型的充分性以及该极限的校准，并在三个 IBM 动态电路上开展预先设定的 2^3 因子实验加以检验。对于主要的回波旁观者可观测量，延迟-测量系数为 b_{LM}=+0.0007，名义 95% bootstrap 区间为 [-0.0033,+0.0049]。一项单独规划的后续实验满足 ±0.005 的等价性判据，并恢复出两个注入的交互作用；但两次重复运行均触发漂移规则。多旋钮外推的中位绝对误差小于单旋钮比较，然而在六个可观测量中的三个上，全部五种原始策略均排除了已知的理想值。时长对照支持旁观者亏缺中存在模型依赖的贡献，其来源是原生填充与附加延迟中不相等的衰减率。本文给出一个显式构造，说明为何在两个测量旋钮水平上的测量无法在缺乏响应假设的情况下识别外推极限。事后精度分析与加性全因子估计量揭示了点误差比较所掩盖的进一步偏差-方差权衡。该实验提供的是对所实现响应曲面的诊断，而非对物理通道独立性或缓解准确性的证明。

结构化评述

研究问题

论文研究的问题是：在动态量子电路中，分别放大门、延迟和中电路测量误差所得的可分离性，是否足以证明零噪声外推的准确性；并区分可观测量的可分离性、响应模型的充分性与零噪声极限的校准这三个不同问题。

方法

在三个 IBM 动态电路上开展预先设定的 2^3 因子实验；以回波旁观者可观测量为主要对象，估计延迟-测量交互系数 b_{LM} 并给出 bootstrap 区间；另设满足 ±0.005 等价性判据的后续实验并注入交互作用；比较单旋钮与多旋钮外推策略的误差；设置时长对照以考察衰减率差异；给出关于两个测量旋钮水平无法识别外推极限的显式构造；并进行事后精度分析与加性全因子估计。

主要发现

主要回波旁观者可观测量的延迟-测量系数为 b_{LM}=+0.0007，名义 95% bootstrap 区间为 [-0.0033,+0.0049]；后续实验满足 ±0.005 等价性判据并恢复出两个注入交互作用，但两次重复运行均触发漂移规则；多旋钮外推的中位绝对误差小于单旋钮比较，但在六个可观测量中的三个上，全部五种原始策略均排除了已知理想值；时长对照支持旁观者亏缺中存在来自原生填充与附加延迟中不相等衰减率的模型依赖贡献；显式构造表明在两个测量旋钮水平上的测量无法在缺乏响应假设时识别外推极限；事后精度分析与加性全因子估计量揭示了点误差比较所掩盖的偏差-方差权衡。

局限与展望

论文明确指出，该实验提供的是对所实现响应曲面的诊断，而非对物理通道独立性或缓解准确性的证明；因此其结果不应被解读为零噪声外推已获认证。局限包括：结论基于三个 IBM 动态电路与特定可观测量，重复运行触发漂移规则提示稳定性约束；两个测量旋钮水平无法在无响应假设下识别外推极限。可合理推断的后续方向是：在明确响应假设下设计更多测量旋钮水平的实验，并同时报告偏差-方差权衡而非仅比较点误差；上述方向属于推断，原文未作实证。

相互作用量子参考系主分类

2610.28732v1

Interacting quantum reference frames

作者：Leonardo Chataignier、Alexander R. H. Smith

主分类：quant-ph 公告类型：new

quant-ph gr-qc hep-th

中文摘要

本文在规范理论的狄拉克量子化框架内构建量子参考系：物理态由运动学希尔伯特空间 $\mathcal{H}_{\rm kin}$ 经群平均得到。假设规范群 $G$ 为幺模群，并将量子参考系定义为与作用于 $\mathcal{H}_{\rm kin}$ 某一张量因子的参考系取向群 $G_R$ 相联系的相干态系统。类比路径积分中的 Faddeev-Popov 程序，我们证明物理内积可借助参考系取向的选择及相应的算符测度写出，而物理希尔伯特空间与该选择无关。由此得到 Page-Wootters 约化映射的推广，用于定义条件态以及在给定参考系取向时测量结果的条件概率；这些概率对应于由既有相对化映射的推广所得到的关系型狄拉克可观测量的期望值。主要结果是：即使 $G$ 在 $\mathcal{H}_{\rm kin}$ 的因子分解上不表现为张量积表示，实现参考系变换的映射仍是幺正的。因此该形式体系可容纳参考系与相对于其描述的系统之间的相互作用。我们将该形式体系应用于时间参考系，证明在时钟与系统相互作用时出现幺正的薛定谔方程，并在适当极限下恢复此前报道的时间非局域薛定谔方程；借助物理内积中的规范固定测度，非幺正性问题得以避免。我们还讨论了相互作用空间参考系的情形，表明一个参考系中的相干性与另一参考系中的纠缠之间的已知对应关系依赖于耦合。

结构化评述

研究问题

如何在狄拉克量子化规范理论中定义量子参考系，并在参考系与系统存在相互作用、规范群不按张量积方式作用时，构造参考系变换、条件态与关系型可观测量，同时保持幺正性。

方法

在幺模规范群假设下，以群平均从运动学希尔伯特空间构造物理态；将量子参考系定义为与参考系取向群相联系的相干态系统；类比 Faddeev-Popov 程序，用参考系取向选择与算符测度表示物理内积；推广 Page-Wootters 约化映射与相对化映射以定义条件态、条件概率和关系型狄拉克可观测量；并应用于时间参考系与空间参考系。

主要发现

物理内积可借助参考系取向的选择与相应算符测度写出，但物理希尔伯特空间不依赖于该选择；所得条件概率对应关系型狄拉克可观测量的期望值；即使规范群在 $\mathcal{H}_{\rm kin}$ 的因子分解上不表现为张量积表示，实现参考系变换的映射仍是幺正的；在时间参考系情形中，相互作用时钟与系统给出幺正薛定谔方程，并在适当极限下恢复此前报道的时间非局域薛定谔方程，物理内积中的规范固定测度避免了非幺正性问题；在空间参考系情形中，一个参考系中的相干性与另一参考系中的纠缠之间的对应关系依赖于耦合。

局限与展望

该形式体系适用于幺模规范群，其结论依赖于群平均与相干态参考系的构造；非幺模群及更一般的参考系取向群情形未在原文中处理。可合理推断的后续方向包括：将框架推广至非幺模规范群，进一步考察相互作用对空间参考系中相干性与纠缠对应关系的定量影响，以及在具体引力或规范理论模型中检验该参考系变换映射的幺正性。

作者：Mingyuan Wang、Stefan Krastanov

中文摘要

Calderbank--Shor--Steane（CSS）码通过分离的纯 $X$ 与纯 $Z$ 稳定子校验支持解码与容错逻辑操作，但生成元的选择与单量子比特 Clifford 变换可能掩盖这一结构。本文给出一个确定性多项式时间算法，用于判定任意稳定子码是否在局部 Clifford 变换下等价于某个 CSS 码，并在存在这种形式时构造所需的变换与 CSS 校验。对于 $n$ 个量子比特上 $m$ 行可能冗余的生成元，该算法使用 $O(mn^2+n^4)$ 次二元域运算。作者通过刻画保持二元稳定子标签张成空间的局部投影算子，将问题归约为仿射线性系统。该转换保持码参数，并对量子低密度奇偶校验（qLDPC）码保持校验稀疏性。文中演示了 CSS 结构的恢复与解码器复用，并解决了已发表码构造中此前悬而未决的 LC-to-CSS 分类问题。对于图态，LC-to-CSS 等价对应于局部补运算轨道中存在二部图；作者导出该性质的充要邻接矩阵判据，并在存在时构造相应图。该算法使 CSS 解码与容错构造可在 CSS 码的整个局部 Clifford 等价类中得以利用。

结构化评述

研究问题

如何判定任意稳定子码是否在局部 Clifford 变换下等价于 CSS 码，并在存在时构造相应变换与 CSS 校验。

方法

提出确定性多项式时间算法；通过刻画保持二元稳定子标签张成空间的局部投影算子，将问题归约为仿射线性系统；对图态导出基于邻接矩阵的充要判据并构造二部图。

主要发现

算法对 $n$ 个量子比特上 $m$ 行可能冗余的生成元使用 $O(mn^2+n^4)$ 次二元域运算；转换保持码参数并对 qLDPC 码保持校验稀疏性；演示了 CSS 恢复与解码器复用，并解决了已发表码构造中此前悬而未决的 LC-to-CSS 分类问题；对图态给出 LC-to-CSS 等价的充要邻接矩阵判据。

局限与展望

中文摘要

容错量子计算机需要快速且准确的错误解码。本文提出 CoDecoder，一种小型神经前端，可与现有解码器组合，以提高准确率并降低平均解码时间。该前端预测每个 shot 的逻辑结果，保留置信度高的预测，并将剩余 shot 路由至未改动的回退解码器。一种逻辑算符感知的输出头对平移后的逻辑算符进行评分，在表面码上合并等价的逻辑线，在双变量自行车（BB）码上联合判定逻辑量子比特。融合 GPU 推理与高效路由降低了每个 shot 的开销。在电路级噪声下的注册测试中，与关联匹配相比，组合方法在距离 7–17 的表面码上将失败率降低 6.4–31.4%；与全 DEM Relay-BP 相比，在两个 BB 码上降低 22–50%，且在这些比较中实现 2.3–124 倍加速。与我们重新实现的神经解码器 Cascade 相比，组合方法在全部四种设置中均降低了解码时间。对路由后的 shot 由两个解码器联合判定，保持了该速度，并使组合方法在全部四种设置中比 Cascade 更准确，在 [[72,12,6]] 码上失败率降低 14–18%。在 [[72,12,6]] BB 码上，在匹配训练条件下，采用独立逻辑输出的传统输出头的失败频率是本文联合类别评分的 3.8–5.0 倍。逐 shot 分析展示了组合方法如何获得准确率提升：在保留的 shot 上，即使前端整体准确率较低，其纠正的回退错误仍多于引入的错误。
