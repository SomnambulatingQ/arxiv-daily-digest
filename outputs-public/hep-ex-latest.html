中文摘要

本工作利用费米实验室短基线近探测器（SBND）给出了氩核上电子中微子带电流总截面与单微分截面的测量结果。我们给出了迄今统计量最高的包含性 $\nu_e + \bar\nu_e$（95.2% $\nu_e$ 与 4.8% $\bar\nu_e$）带电流截面测量，以及首个利用 Booster Neutrino Beam 的包含性 $\nu_e + \bar\nu_e$ 截面测量。对该通道的直接测量对于未来通过电子中微子出现研究长基线与短基线中微子振荡至关重要，而这些研究对于回答中微子唯象学中的开放问题以及在高强度前沿寻找超出标准模型物理十分关键。本工作所用数据对应 $8.81 \times10^{19}$ 个质子打靶的曝光量，在电子能量至少为 500 MeV 的条件下选出 729 个候选事例。单微分截面按电子能量及相对于束流轴的夹角提取。在所选事例的预测平均中微子能量 $\langle E_\nu\rangle=1.8$ GeV 下，通量平均的总截面测量值为 $\sigma= [3.90 \pm 0.18\,\text{(stat)} \pm 0.41\,\text{(syst)}] \times 10^{-39}$ cm$^2$/nucleon。总截面与微分截面均与常用中微子事例产生器的预测进行了比较。数据更倾向于那些预测总体截面较低的产生器。

结构化评述

研究问题

在氩核上测量包含性电子中微子（$\nu_e + \bar\nu_e$）带电流的总截面与单微分截面，并与常用中微子事例产生器的预测进行比较。

方法

利用费米实验室短基线近探测器（SBND）与 Booster Neutrino Beam，在 $8.81 \times10^{19}$ 个质子打靶的曝光量下，以电子能量至少 500 MeV 为条件选出 729 个候选事例；按电子能量及相对于束流轴的夹角提取单微分截面，并给出通量平均的总截面。

主要发现

测得通量平均总截面为 $\sigma= [3.90 \pm 0.18\,\text{(stat)} \pm 0.41\,\text{(syst)}] \times 10^{-39}$ cm$^2$/nucleon（所选事例预测平均中微子能量 $\langle E_\nu\rangle=1.8$ GeV）；该测量为迄今统计量最高的氩核包含性 $\nu_e + \bar\nu_e$ 带电流截面测量，也是首个利用 Booster Neutrino Beam 的此类测量；数据与常用事例产生器比较后更倾向于预测总体截面较低者。

局限与展望

原文指出该通道的直接测量对未来长基线与短基线中微子振荡中电子中微子出现的研究十分关键；摘要未讨论系统误差来源细节、模型依赖性或更广的适用能量范围，相关后续方向需进一步分析方能确定。

ALICE 实验中质子-质子碰撞下的粲夸克与底夸克产生主分类

2611.26017v1

Charm and beauty production in pp collisions with ALICE

作者：Jianhui Zhu

主分类：hep-ex 公告类型：new

hep-ex

中文摘要

在质子-质子（pp）碰撞中测量粲夸克与底夸克的产生，为微扰量子色动力学（pQCD）提供了关键检验，也为研究重夸克强子化提供了独特途径。本报告介绍 ALICE 近期的一组结果，重点为 LHC Run 3 的测量。文中讨论了 $\sqrt{s}=5.36$ 和 13.6 TeV 下瞬发 D 介子的横动量微分产生截面，以及 $\sqrt{s}=13.6$ TeV 下全重建 B 介子的横动量微分产生截面，并与理论计算进行了比较。粲夸克与底夸克产生的快度依赖，以及 $\rm D^{*+}/D^0$ 和 $\rm Λ_c^+/D^0$ 产额比，为重夸克产生与强子化提供了互补的约束。对源自底强子衰变的 ${\rm J}/\psi$ 和 $\psi({\rm 2S})$ 份额的测量，以及对 inclusive $\psi({\rm 2S})$ 与 ${\rm J}/\psi$ 产生比值的测量，进一步约束了微扰重夸克产生与非微扰束缚态形成之间的相互作用。

结构化评述

研究问题

在质子-质子碰撞中，粲夸克与底夸克的产生截面、快度依赖、强子化相关的产额比以及夸克偶素产生，能否被微扰 QCD 计算和重夸克强子化模型描述？

方法

利用 ALICE 探测器在 LHC Run 3 的 pp 碰撞数据，测量 $\sqrt{s}=5.36$ 和 13.6 TeV 下瞬发 D 介子以及 $\sqrt{s}=13.6$ TeV 下全重建 B 介子的横动量微分产生截面，并测量粲夸克与底夸克产生的快度依赖、$\rm D^{*+}/D^0$ 与 $\rm Λ_c^+/D^0$ 产额比、源自底强子衰变的 ${\rm J}/\psi$ 与 $\psi({\rm 2S})$ 份额以及 inclusive $\psi({\rm 2S})/{\rm J}/\psi$ 产生比值，并与理论计算进行比较。

主要发现

摘要给出了上述观测量与理论计算之间的比较，并指出快度依赖和 $\rm D^{*+}/D^0$、$\rm Λ_c^+/D^0$ 产额比为重夸克产生与强子化提供了互补约束；底强子衰变来源的 ${\rm J}/\psi$、$\psi({\rm 2S})$ 份额及 $\psi({\rm 2S})/{\rm J}/\psi$ 比值进一步约束微扰重夸克产生与非微扰束缚态形成之间的相互作用。摘要未给出具体的数值结论。

局限与展望

该贡献为会议报告，摘要未展开系统误差、理论模型细节及适用范围；相关测量对重夸克强子化模型的区分能力，以及 Run 3 更高统计量下对上述观测量的进一步检验，可视为合理的后续方向，但需以原文后续分析为准。

中文摘要

开放中微子数据的日益可得为更广泛地检验相互作用模型提供了条件，但一个关键障碍仍然存在：将理论预测映射到重建观测量此前需要计算密集的方法，而这些方法在原始实验合作组之外难以获得。本文提出一个 MINERvA 探测器响应的概率替代模型，该模型在开放模拟数据集上训练，可将生成器层面的末态粒子与相互作用几何映射到重建观测量，且不依赖生成器特定的相互作用标签。作者通过条件响应分布、重建观测量以及基于分类器的闭合检验评估其保真度。进一步地，为展示超越传统依赖相空间重加权局限的泛化能力，作者在训练中完全剔除两粒子-两空穴相互作用，并表明该替代模型在估计的不确定度范围内再现了其重建响应。在面向 MINERvA 带电流包容性缪中微子数据的端到端应用中，该模型再现了选择效率与纯度，并将 GENIE、NuWro 和 GiBUU 的预测前向折叠以与测量直接比较。通过将理论预测移入重建空间而非对数据做展开，本工作在中微子相互作用模型与实验观测之间建立了一个可复用的接口，扩展了通过开放数据集可触及的物理范围。

目前尚无计划中的中微子实验有望超越大亚湾在 \(\theta_{13}\) 上的精度；要超越它，需要创新策略以降低统计与系统不确定度。本文研究一种未来方案：将可移动的反应堆反中微子源置于距江门地下中微子天文台（JUNO）探测器较短的基线（\(L\lesssim 3\,\mathrm{km}\)）处。由于 JUNO 具有大的有效质量，即使相对较小的反应堆也能在数年内产生统计显著的事件数，以探测由 \(\theta_{13}\) 设定的 \(\lesssim 8.7\%\) 的 \(\bar{\nu}_e\) 消失。我们考虑两种可能：位于通往地下实验室通道旁侧洞室中的 \(\mathcal{O}(20\,\mathrm{MW}_{\mathrm{th}})\) 微型反应堆，以及位于地表的 \(\mathcal{O}(400\,\mathrm{MW}_{\mathrm{th}})\) 机组。两种情形下，反应堆均由源附近的小型通量监测探测器观测，而 JUNO 在两个基线处测量反中微子通量，从而压低相关的通量与探测器系统误差。利用测得的大亚湾逐同位素能谱及其协方差，我们为微型反应堆建模了高丰度低浓缩铀（HALEU）堆芯，为地表机组建模了低浓缩铀（LEU）堆芯，并讨论了各类潜在系统不确定度来源及其对 \(\theta_{13}\) 精度的影响。地下微型反应堆可在十年内将 JUNO 的灵敏度提高三至四倍，达到 \(\delta\sin^2 2\theta_{13}\simeq 4\%\)；而地表反应堆若能在反应堆迁移过程中将发射率监测至亚百分比水平，则可在约三年内达到当前全局拟合精度 \(\delta\sin^2 2\theta_{13}=2.5\%\)。
