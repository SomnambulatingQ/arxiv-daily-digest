探索大型强子对撞机小碰撞系统中部分子集体性的极限主分类

2611.08327v1

Exploring the limit of partonic collectivity in small collision systems at the LHC

作者：ALICE Collaboration

主分类：nucl-ex 公告类型：new

nucl-ex hep-ex

中文摘要

此前已通过ALICE实验记录的高多重数p-Pb碰撞（√s_NN = 5.02 TeV）和pp碰撞（√s = 13 TeV）中介子（π±、K±、K_S^0）与重子（p(p̄)、Λ(Λ̄)）的椭圆流（v_2）测量，研究了小碰撞系统中部分子相的存在。结果表明，在中等横动量（p_T）区域，重子与介子的v_2呈现出分组与劈裂行为，从而确认在重离子碰撞中观测到的部分子集体性同样存在于这些系统中。本文进一步研究了p-Pb碰撞中多重数区间N_ch ≥ 50、25 ≤ N_ch < 50和15 ≤ N_ch < 25，以及pp碰撞中25 ≤ N_ch < 50和15 ≤ N_ch < 25内多种强子种类的p_T微分v_2。其中N_ch为在|η| < 0.8和0.2 < p_T < 3.0 GeV/c运动学区域内产生的、经效率修正的带电粒子数。本文考察了v_2特征性的质量依赖关系以及已鉴别粒子间的分组与劈裂模式。p-Pb和pp碰撞中N_ch ≥ 25的结果与部分子集体性的发展相一致。在低多重数区间15 ≤ N_ch < 25，由重子与介子v_2比值量化的重子-介子v_2劈裂总体上与更高多重数时一致；然而，由于实验不确定度较大，其显著性在p-Pb碰撞中降至约2σ，在pp碰撞中降至小于1σ。这些测量是确定LHC小碰撞系统中部分子流极限的第一步。

结构化评述

研究问题

在LHC的小碰撞系统（高多重数p-Pb与pp碰撞）中，部分子集体性是否存在，其可观测特征（v_2的质量依赖及重子-介子分组与劈裂）能否延伸至更低多重数区间，从而界定部分子流的极限。

方法

利用ALICE实验数据，在p-Pb碰撞（√s_NN = 5.02 TeV）的N_ch ≥ 50、25 ≤ N_ch < 50、15 ≤ N_ch < 25区间以及pp碰撞（√s = 13 TeV）的25 ≤ N_ch < 50、15 ≤ N_ch < 25区间，测量多种已鉴别强子（π±、K±、K_S^0、p(p̄)、Λ(Λ̄)）的p_T微分椭圆流v_2，并考察其质量依赖关系及重子-介子v_2比值所量化的分组与劈裂模式。

主要发现

p-Pb和pp碰撞中N_ch ≥ 25的结果与部分子集体性的发展相一致；在15 ≤ N_ch < 25的低多重数区间，重子-介子v_2劈裂总体上与更高多重数时一致，但其显著性因实验不确定度较大而在p-Pb碰撞中降至约2σ、在pp碰撞中降至小于1σ。

局限与展望

原文指出这些测量是确定LHC小碰撞系统中部分子流极限的第一步；低多重数区间劈裂显著性的降低主要归因于实验不确定度，尚不能据此判定部分子集体性在该区间消失。后续需更高统计精度或改进的测量以明确其下限，此为进一步研究的合理推断而非原文结论。

各向异性流的测量为超相对论重离子碰撞中产生的夸克-胶子等离子体的集体膨胀与输运性质提供了最强约束之一。本文利用 ALICE 探测器在质心能量 $\sqrt{s_{\rm{NN}}} = 5.02$ TeV 的 Pb-Pb 碰撞和 $5.44$ TeV 的 Xe-Xe 碰撞中测量了各向异性流系数 $v_{2}$、$v_{3}$ 和 $v_{4}$ 的关联与涨落。基于约化流矢量 $q_{n}$ 的事件形状工程技术被用于研究不同初始态几何下的流关联。观测到 $v_2$ 与 $v_3$ 之间存在强反关联，$v_2$ 与 $v_4$ 之间为正关联，$v_3$ 与 $v_4$ 之间存在弱反关联。由 $v_2$-$v_4$ 关联提取了 $v_4$ 的线性与非线性分量，并与多粒子关联方法提取的结果进行了比较。本文首次在 Pb-Pb 和 Xe-Xe 碰撞中直接测量了 $v_{4}$ 的线性与非线性分量随 $q_2$ 的变化，结果显示非线性项与初始态椭率 $\varepsilon_2$ 强耦合，而线性分量对初始态几何的依赖很弱。此外，提取了表征 $v_2^2$ 对 $v_4$ 非线性贡献的耦合系数 $\chi_{4,22}$，除在极中心碰撞外，其随 $q_2$ 的依赖很小。本文首次利用事件形状工程结合 $v_2\{2\}$ 与 $v_2\{4\}$ 的比值研究了受约束初始态几何下的流涨落效应；结果表明，与无偏比值相比，$q_2$ 最低的碰撞表现出更显著的 $v_2$ 涨落。

方法

主要发现

中文摘要

负μ子在物质中被俘获时伴随俄歇电子发射并形成带正电的μ子离子。这种电荷反转现象为通过电磁方式提取μ子俘获产物提供了可能。本文提出一种基于电荷反转的μ子离子提取方案：先将负μ子在稀薄气体环境中减速并约束，待其完成转换后，再利用静电场对生成的μ子离子进行加速和提取。我们通过对μ子减速、μ子离子形成、电荷交换以及气体介质中加速等竞争过程进行量级估计，考察了该概念的可行性。本文提出一种磁-静电减速方案，用于减小实际低能μ子束的横向相空间，同时保持纵向运动可控，并与静电俘获区直接匹配。分析表明，μ子寿命内完成μ子离子形成与提取并未被基本时间尺度约束所排除，但由于若干相关低能截面和电荷态布居在实验上约束不足，定量效率仍不确定。

中文摘要

微像素室（μ-PIC）是一类微结构气体探测器（MPGD），其像素电极结构类似于切片正比计数器。传统上，μ-PIC电极连接至正交条形电极以减少读出电路数量；然而，这种配置在追踪缠绕径迹或高计数率运行时引入多击歧义。解决该问题的已知方案是采用附加读出轴。为此，我们利用Garfield++模拟设计了一种新的电极结构，并基于玻璃通孔（TGV）技术制作了三轴μ-PIC。该三轴μ-PIC在5.9 keV下实现了1.1×10^4的高气体增益和22%（FWHM）的能量分辨率。此外，对于间距超过3 mm的两个簇，在95%置信水平下误击概率小于0.78%，与Garfield++预测一致。利用该三轴μ-PIC，从三个独立读出条形电极（阳极和两个阴极）收集单雪崩信号，这些电极间的电荷比几乎保持恒定，为阳极:U阴极:V阴极=3:2:1。此外，我们通过采用替代工作模式，在不增加放电风险的情况下成功实现了3.2×10^4的增强增益。

中文摘要

最近在欧洲核子研究中心大型强子对撞机上进行的超相对论 $^{16}$O+$^{16}$O 与 $^{20}$Ne+$^{20}$Ne 碰撞，通过出射强子的集体流成像了核子间的四极与八极关联。本文建立了这些关联与进入手征核子间相互作用的低能常数（LECs）之间的定量联系。基于子空间投影耦合簇方法构建的代理模型，使得对基态四极均方偏心率的全局敏感性分析成为可能，结果表明四极关联对手征展开次次领头阶（next-to-next-to-leading order）的全部 16 个 LECs 呈线性且可加的响应。这些敏感性在 $^{16}$O 与 $^{20}$Ne 中差异显著，且与结合能和电荷半径——通常用于标定核相互作用的体观测量——的敏感性互补。特别地，$^{20}$Ne 碰撞主要探测两核子相互作用的自旋-轨道部分。因此，轻离子碰撞中的软粒子关联构成了一类研究核力及其从量子色动力学中涌现的新数据。

研究问题

方法

采用基于子空间投影耦合簇方法构建的代理模型（emulators），对 $^{16}$O 与 $^{20}$Ne 基态四极均方偏心率进行全局敏感性分析，并与结合能、电荷半径等体观测量的敏感性进行比较。
