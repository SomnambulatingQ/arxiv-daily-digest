中文摘要

本文报告了在伴随同号 $W$ 玻色子对及两个前向喷注的条件下电弱产生希格斯玻色子（$W^{\pm}W^{\pm}Hjj$）的搜寻。分析使用大型强子对撞机 ATLAS 探测器在质心能量 $\sqrt{s}=13$ TeV 下记录的完整 Run 2 质子-质子碰撞数据，对应积分亮度 140 fb$^{-1}$。搜寻针对两个 $W$ 玻色子均轻子衰变的事件，末态包含两个同号带电轻子、缺失横向动量以及一个希格斯玻色子候选者。高动量的希格斯玻色子候选者衰变为 $b\bar{b}$ 对，并被重建为单个大半径喷注。该过程对四重 $WWHH$ 相互作用具有直接灵敏度。对标准模型预言的偏离通过耦合修正因子 $\kappa_{WW}$ 参数化，其中 $\kappa_{WW}=1$ 对应标准模型。未观察到相对于标准模型预言的显著超出。在 95% 置信水平下给出了 $W^{\pm}W^{\pm}Hjj$ 产生截面作为 $\kappa_{WW}$ 函数的上限。观测（预期）结果排除了区间 $-2.1 < \kappa_{WW} < 4.1$（$-1.9 < \kappa_{WW} < 3.9$）之外的 $\kappa_{WW}$ 值。

结构化评述

研究问题

在 $\sqrt{s}=13$ TeV 质子-质子碰撞中，是否存在超出标准模型预言的增强矢量玻色子散射过程 $W^{\pm}W^{\pm}Hjj$ 产生的迹象，并据此约束四重 $WWHH$ 相互作用耦合修正因子 $\kappa_{WW}$。

方法

利用 ATLAS 探测器记录的完整 Run 2 数据（积分亮度 140 fb$^{-1}$），选择两个同号轻子、缺失横向动量以及一个衰变为 $b\bar{b}$ 并重建为单个大半径喷注的希格斯玻色子候选者的事件；通过耦合修正因子 $\kappa_{WW}$ 参数化对标准模型的偏离，并基于 $\kappa_{WW}$ 给出截面上限。

主要发现

未观察到相对于标准模型预言的显著超出；在 95% 置信水平下设定了 $W^{\pm}W^{\pm}Hjj$ 产生截面作为 $\kappa_{WW}$ 函数的上限；观测（预期）排除区间为 $-2.1 < \kappa_{WW} < 4.1$（$-1.9 < \kappa_{WW} < 3.9$）之外。

局限与展望

该结果基于 Run 2 数据，未发现显著信号，因此对 $\kappa_{WW}$ 的约束仍受统计与系统不确定度限制；未来更高亮度或更高能量数据可能提高灵敏度，但本文未给出具体后续计划。

作为可见物质的基本组成单元，强子传统上被夸克模型归类为由夸克-反夸克对组成的介子和由三个价夸克构成的重子。然而，这一经典图像无法解释强相互作用中复杂的手征动力学以及奇异多夸克强子的出现。尽管此类非常规动力学的实验证据已在粲物理领域出现，但开放底系统仍是检验这些机制普适性的长期追寻前沿。本文报告了在底奇扇区观测到一个新共振态，其全局显著性超过七个标准偏差，数据来自欧洲核子研究中心（CERN）大型强子对撞机底物理（LHCb）实验记录的双质子碰撞数据。该共振态表现出窄的自然宽度，且与常规夸克模型预言相比存在显著的质量亏损。这一结果标志着首次观测到非常规的单底强子，为强相互作用的手征动力学以及奇异域中的重夸克自旋对称性提供了关键见解。

结构化评述

研究问题

在开放底（beauty）系统中寻找非常规强子态，以检验在粲扇区出现的奇异多夸克动力学机制是否具有普适性。

方法

利用欧洲核子研究中心（CERN）大型强子对撞机底物理（LHCb）实验记录的双质子碰撞数据，在底奇（beauty-strange）扇区进行共振态搜寻，并报告其全局显著性。

主要发现

观测到一个新的底奇共振态，全局显著性超过七个标准偏差；该态具有窄的自然宽度，且相对于常规夸克模型预言存在显著的质量亏损；这是首次观测到非常规的单底强子。

局限与展望

该结果为强相互作用手征动力学和重夸克自旋对称性在奇异域中的表现提供了关键信息；其理论解释、内部量子数及在底扇区中的普适性仍需进一步实验与理论研究确认。

本文对撞机中带电粒子时间测量技术进行了选择性综述。大致而言，时间测量阵列的演化可划分为三个时代。尽管亮度和多重数决定了探测器技术的选择，但仍有必要审视各种信号捕获与处理方法，以及它们在不断变化的校准条件中所起的作用。在当前时代——高亮度大型强子对撞机（HL-LHC）升级阶段——双阈值时间测量技术能够显著简化对幅度游走（amplitude walk）的关键修正。该修正所覆盖的时间范围通常比目标分辨率大一个数量级。此外，由于在高辐射环境中运行条件不断变化，校准不再能被视作一次性过程。为 CMS 升级设计的 TOFHIR2C ASIC 可被配置以提供双阈值时间测量。在本报告中，我们利用这一能力来展示该技术适用于新时代的潜力。

研究问题

对撞机中带电粒子时间测量阵列的技术演化，特别是在高亮度大型强子对撞机（HL-LHC）升级背景下，如何简化幅度游走修正并应对高辐射环境中的校准挑战。

方法

选择性综述，梳理三个时代的时间测量阵列演化；讨论信号捕获与处理方法；利用为 CMS 升级设计的 TOFHIR2C ASIC 的双阈值时间测量配置能力进行演示。

局限与展望

本文为选择性综述，未给出具体实验数据或定量性能结果；双阈值时间测量技术的实际增益、TOFHIR2C ASIC 的详细性能及在不同探测器系统中的适用性有待进一步实验验证；高辐射环境下的长期校准策略仍需持续研究。

中文摘要

LUX-ZEPLIN（LZ）实验在2.84吨·年曝光中报告了一个核反冲事件，反冲能量为248±23_stat±23_sys keV，局域显著性为3.4σ。非弹性（吸热）暗物质是一个自然的候选者：其运动学阈值抑制低能反冲并将信号移向高反冲能量。我们使用两个边带对LZ数据进行模型无关分析，不指定紫外完备理论，因此结果广泛适用于具有相干自旋无关核散射的非弹性暗物质。对于每个(m_χ,δ)，我们计算N_low/N_sig和N_hi/N_sig——即边带[14,225) keV和(271,800] keV相对于信号区[225,271] keV的预测计数比。这两个比值随δ反向变化，并在唯一的分裂δ^⋆处同时优化。对于m_χ=1 TeV，δ^⋆=339 keV，合并泊松张力约为1.9σ；在500 GeV–3 TeV范围内，δ^⋆处的张力从≲1.3σ升至约2.5σ。额外的抑制来自Helm形状因子：在248 keV处|F_Xe^Helm|^2≈3×10^{-4}，接近其第二衍射零点。在271<E_R<800 keV范围内进行专门的LZ搜索将为δ≳330 keV的非弹性暗物质提供决定性检验。

研究问题

LZ实验报告的高反冲核反冲事件是否可由非弹性（吸热）暗物质解释，以及如何利用边带数据对其进行模型无关约束。
