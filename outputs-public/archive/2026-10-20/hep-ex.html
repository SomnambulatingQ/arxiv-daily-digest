主分类：hep-ex 公告类型：new

中文摘要

BESIII 探测器积累的世界上最大的 $J/\psi$ 事例样本，为通过辐射跃迁过程 $J/\psi\to \gamma\eta/\eta'$ 研究 $\eta$ 与 $\eta'$ 物理提供了独特机会。本文综述了 BESIII 在轻介子谱学方面近期取得的部分亮点成果，包括 $\eta' \to \pi^0\pi^0\eta$ 中 cusp 效应证据、$\eta\to 3\pi$ 与 $\eta' \to 4\pi$ 衰变机制的精确研究、利用 $\eta/\eta' \to \gamma e^+e^-$ 与 $\eta' \to \pi^+\pi^-l^+l^-$ 进行的电磁跃迁形状因子测量，以及针对 $\eta$ 与 $\eta'$ 衰变为轻子对的稀有衰变搜寻，包括 $\eta\to l^+l^-$ 和 $\eta/\eta' \to l^+l^-l^+l^-$（$l = e, \mu$）。

结构化评述

研究问题

如何利用 BESIII 探测器积累的大量 $J/\psi$ 事例，通过 $J/\psi\to \gamma\eta/\eta'$ 辐射跃迁过程研究 $\eta$ 与 $\eta'$ 介子的衰变机制、电磁性质及稀有衰变。

方法

基于 BESIII 探测器采集的 $J/\psi$ 事例样本，通过辐射跃迁 $J/\psi\to \gamma\eta/\eta'$ 获得 $\eta$ 与 $\eta'$ 介子，并对特定衰变道进行实验分析；本文以会议报告形式综述相关近期结果。

主要发现

综述的成果包括：$\eta' \to \pi^0\pi^0\eta$ 中 cusp 效应的证据；$\eta\to 3\pi$ 与 $\eta' \to 4\pi$ 衰变机制的精确研究；利用 $\eta/\eta' \to \gamma e^+e^-$ 与 $\eta' \to \pi^+\pi^-l^+l^-$ 开展的电磁跃迁形状因子测量；以及对 $\eta\to l^+l^-$ 和 $\eta/\eta' \to l^+l^-l^+l^-$（$l = e, \mu$）等稀有衰变的搜寻。

局限与展望

本文为会议综述，未给出各项结果的定量细节与不确定度；其适用范围限于 BESIII 现有 $J/\psi$ 数据所支持的 $\eta$ 与 $\eta'$ 衰变研究。后续可合理推断的方向包括：随着统计量增加对上述 cusp 效应证据与稀有衰变搜寻进行更新，并进一步检验相关衰变机制与形状因子测量。

中文摘要

束流诱导本底会提高高亮度正负电子对撞机的触发与数据获取率，其依赖于束流和机器条件，因此除模拟外还需数据驱动研究。本文利用BESIII记录的实验数据，发展了一种数据驱动的机器学习方法，用于触发层面的束流本底抑制。针对两种触发配置训练并评估了紧凑神经网络分类器：一种仅使用径迹与飞行时间信息，另一种仅使用电磁量能器信息。每个分类器使用BESIII探测器的48个二值Level-1触发条件。模型用于区分强子事件与束流本底事件，并在匹配强子事件效率的条件下与现有触发选择进行比较。相对于现有触发选择，在所研究的配置和质心能量下，束流本底假阳性率降低20-60%，并使用随机触发数据测试了抑制性能的稳定性。面向硬件的综合结果表明，该紧凑网络适合低延迟FPGA实现。该方法可在未来BESIII触发升级中降低触发流中束流本底事件的比例，也为未来高亮度正负电子对撞机的触发优化提供参考。

研究问题

在高亮度正负电子对撞机上，束流诱导本底会抬高BESIII触发与数据获取率；论文研究如何利用实验数据在触发层面抑制束流本底，并在匹配强子事件效率的条件下与现有触发选择比较。

主要发现

模型能够区分强子事件与束流本底事件；相对于现有触发选择，在所研究的配置和质心能量下，束流本底假阳性率降低20-60%；使用随机触发数据测试时抑制性能稳定；面向硬件的综合结果表明该紧凑网络适合低延迟FPGA实现。

作者：Lucas Foreman

中文摘要

本文报告了利用 LHCb Run 2 数据对 b 强子时间依赖性质的最新测量，包含三项结果。第一项是利用 $B_s^0\to J/\psi\pi^+\pi^-$ 衰变对 CKM 相位 $\phi_s$ 的测量，该结果改进了该道中的测定，得到 $\phi_s = -77\pm34(\text{stat})\pm7(\text{syst})$ mrad；该结果被纳入 LHCb 全局平均，得到 $\phi_s = -41\pm17$ mrad。第二项是利用 $B^0\to J/\psi\rho^0(770)$ 对 $\phi_s$ 测量中企鹅贡献 $\Delta\phi_s$ 的确定，该测量首次在 $B^0\to J/\psi\rho^0(770)$ 衰变中观测到 CP 破坏，测得 CKM 相位 $2\beta^{\text{eff}}_{ccd} = 0.710\pm0.084\pm0.051$ rad，并给出对企鹅贡献的最严格限制 $\Delta\phi_s = 5.0\pm4.6$ mrad。第三项是利用 $B_s^0 \to K_S \mu^+ \mu^-$ 衰变首次在 $b\to s l^+ l^-$ 过程中测量时间依赖 CP 破坏，确定该衰变的时间依赖系数为 $C=-0.13\pm0.32(\text{stat})\pm0.04(\text{syst})$ 和 $S=+0.82\pm0.29(\text{stat})\pm0.05(\text{syst})$。

结构化评述

研究问题

利用 LHCb Run 2 数据测量 b 强子的时间依赖性质，包括 CKM 相位 $\phi_s$、企鹅贡献 $\Delta\phi_s$ 以及 $b\to s l^+ l^-$ 过程中的时间依赖 CP 破坏。

方法

基于 LHCb Run 2 数据，分别分析 $B_s^0\to J/\psi\pi^+\pi^-$、$B^0\to J/\psi\rho^0(770)$ 和 $B_s^0 \to K_S \mu^+ \mu^-$ 衰变的时间依赖行为，提取 CP 相关参数并与全局平均结合。

主要发现

$B_s^0\to J/\psi\pi^+\pi^-$ 给出 $\phi_s = -77\pm34(\text{stat})\pm7(\text{syst})$ mrad，纳入 LHCb 全局平均后为 $\phi_s = -41\pm17$ mrad；$B^0\to J/\psi\rho^0(770)$ 首次观测到 CP 破坏，测得 $2\beta^{\text{eff}}_{ccd} = 0.710\pm0.084\pm0.051$ rad，并给出最严格的企鹅贡献限制 $\Delta\phi_s = 5.0\pm4.6$ mrad；$B_s^0 \to K_S \mu^+ \mu^-$ 给出 $C=-0.13\pm0.32(\text{stat})\pm0.04(\text{syst})$ 和 $S=+0.82\pm0.29(\text{stat})\pm0.05(\text{syst})$。

局限与展望

摘要未讨论局限性或后续方向；基于现有结果可合理推断，需更大统计量以降低统计不确定度并进一步检验这些观测，但此推断并非原文结论。

主要发现

该框架被应用于MADMAX暗物质实验，用测得的反射率校准存在缺陷的盘式增强器模拟器，并推断不可观测的轴子信号功率增强因子；MADMAX实验上的实验验证仍在进行中。
