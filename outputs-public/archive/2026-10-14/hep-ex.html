中文摘要

许多量子引力理论预言普朗克尺度的时空涨落。中微子仅通过弱相互作用和引力相互作用，能够在长距离传播中保持量子相干性；普朗克尺度的涨落会破坏这种相干性，从而在长基线中衰减味振荡概率。这使中微子成为对普朗克尺度物理敏感的干涉仪。本文利用IceCube探测到的368,071个大气中微子，在0.5-100 TeV能量范围内搜寻量子退相干，其能量比此前任何退相干搜寻高一个数量级。我们未发现退相干证据，并对该类中微子退相干模型给出了迄今最强的限制；对于退相干率按 $E^2$ 和 $E^3$ 标度的情形，限制较此前改善超过一个数量级。这些结果排除了所有能量标度 $E^n$（$0\leq n \leq 3$）下自然的普朗克抑制退相干，其中对 $n=3$ 的排除是首次在普朗克尺度上实现。

结构化评述

研究问题

量子引力预言的普朗克尺度时空涨落是否会破坏中微子的量子相干性，从而在长基线味振荡中表现为退相干；以及能否利用高能大气中微子对此类退相干模型给出限制。

方法

使用IceCube探测到的368,071个大气中微子，能量范围为0.5-100 TeV，搜寻量子退相干效应；分析退相干率随能量标度 $E^n$（$0\leq n \leq 3$）变化的模型，并与先前结果比较。

主要发现

未发现退相干的证据；给出了迄今对该类中微子退相干模型最强的限制，对退相干率按 $E^2$ 和 $E^3$ 标度的情形，限制较此前改善超过一个数量级；排除了所有 $0\leq n \leq 3$ 能量标度下自然的普朗克抑制退相干，其中对 $n=3$ 的排除为普朗克尺度上的首次。

局限与展望

结果依赖于所考虑的退相干模型类及IceCube大气中微子数据；对更一般或非普朗克抑制的退相干参数化、其他能量标度或不同中微子源（如天体物理中微子）的适用性尚待进一步研究，后续可通过更高能量或更大统计量的中微子观测检验。

中文摘要

本文首次报道了在双强子 $K^+\pi^-$ 质量 $m_{K\pi}$ 位于 $1000 < m_{K\pi} < 1835\,\text{MeV}/c^{2}$ 区间内 $B^{0} \to K^{+}\pi^{-}\mu^{+}\mu^{-}$ 衰变微分分支比的测量。该衰变模式由夸克级跃迁 $b \to s\ell^{+}\ell^{-}$ 主导，其测量到的有效耦合与标准模型预期存在张力。分析使用 LHCb 探测器在 2011 至 2018 年间收集的质子-质子对撞数据，对应积分亮度为 $8.4\,\text{fb}^{-1}$。微分分支比在双缪子质量平方 $q^2$ 的区间 $0.1 < q^2 < 18.0\,\text{GeV}^2/c^{4}$ 内按不同区域测定，并在 $1.1 < q^2 < 6.0\,\text{GeV}^2/c^{4}$ 区间内按不同 $m_{K\pi}$ 区域测定。这些结果代表了在所选双强子质量区域内首次对分支比随 $m_{K\pi}$ 变化的微分测量，以及在该区域内 $J/\psi$ 共振峰以上首次观测到该衰变。

结构化评述

研究问题

在双强子质量 $1000 < m_{K\pi} < 1835\,\text{MeV}/c^{2}$ 区域内，$B^{0} \to K^{+}\pi^{-}\mu^{+}\mu^{-}$ 衰变的微分分支比如何随双缪子质量平方 $q^2$ 和 $K^+\pi^-$ 质量 $m_{K\pi}$ 变化？

方法

利用 LHCb 探测器在 2011–2018 年收集的质子-质子对撞数据（积分亮度 $8.4\,\text{fb}^{-1}$），在 $0.1 < q^2 < 18.0\,\text{GeV}^2/c^{4}$ 内按不同 $q^2$ 区域以及在 $1.1 < q^2 < 6.0\,\text{GeV}^2/c^{4}$ 内按不同 $m_{K\pi}$ 区域测量 $B^{0} \to K^{+}\pi^{-}\mu^{+}\mu^{-}$ 的微分分支比。

主要发现

首次在 $1000 < m_{K\pi} < 1835\,\text{MeV}/c^{2}$ 区域内测量了 $B^{0} \to K^{+}\pi^{-}\mu^{+}\mu^{-}$ 的微分分支比；在 $0.1 < q^2 < 18.0\,\text{GeV}^2/c^{4}$ 内按不同 $q^2$ 区域以及在 $1.1 < q^2 < 6.0\,\text{GeV}^2/c^{4}$ 内按不同 $m_{K\pi}$ 区域给出了结果；这是首次在所选双强子质量区域内对分支比随 $m_{K\pi}$ 变化的微分测量，也是在该区域内 $J/\psi$ 共振峰以上首次观测到该衰变。

局限与展望

原文未明确讨论局限或后续方向。该测量限于 $1000 < m_{K\pi} < 1835\,\text{MeV}/c^{2}$ 和 $0.1 < q^2 < 18.0\,\text{GeV}^2/c^{4}$ 区域，其精度受统计和系统误差影响；可合理推断，未来更高统计量的数据将有助于检验 $b \to s\ell^{+}\ell^{-}$ 有效耦合与标准模型之间的张力。
